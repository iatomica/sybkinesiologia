# Consultorio de Salud Integral

Sitio web oficial y portal de atención para **Consultorio de Salud Integral** (Cooperativa de Trabajo Salud Integral Ltda.), centro especializado en salud sexual, reproductiva y no reproductiva, ginecología y vasectomía sin bisturí en Córdoba Capital.

- **Ubicación:** Paso de los Andes 17, Barrio Alberdi, Córdoba Capital
- **Teléfono / WhatsApp:** (0351) 422-6320 / +54 9 351 422-6320
- **Instagram:** [@consultoriosaludintegral](https://www.instagram.com/consultoriosaludintegral/?hl=es) (+8.500 seguidores)
- **Obras Sociales:** OSDE, APROSS, Sanitas Salud, UENO Salud y atención particular.

## Stack Tecnológico
- React 19 + TypeScript
- Vite 8
- Tailwind CSS v4 (`@tailwindcss/vite`)
- Lucide React
- Nginx 1.27 en Docker multi-etapa
